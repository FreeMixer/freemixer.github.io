    Class ChannelMuteResource

    Channel mute as a ConsoleResource: /channel/{kind}/{index}/mute.

    {kind}/{index} is TWO path segments (issue #438) — /channel/main/1/mute, /channel/input/3/mute — resolved by channelIdOf, the one parser every channel-addressed entity uses. The kind is always explicit: this entity reaches beyond the input tier because a mains-scoped panic targets a BUS (spec §4.3), and a grammar where only inputs get a short spelling is two grammars. Anything unparseable — a float, an unknown kind — is a not-found, never a defaulted channel.
