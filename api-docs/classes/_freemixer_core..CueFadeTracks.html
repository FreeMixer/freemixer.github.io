      Start a track, REPLACING any live one on the same parameter (§5.5): the new one begins at the parameter's current (mid-fade) value, on the new cue's timing — no jump back to the old start, no jump forward to the old target. A fade whose from already is its to, or whose time is 0, has nothing to walk and is not started (returns false; the old track, if any, is still dropped, because this cue now governs the parameter).

    tick

    • tick(now: number, io: FadeIO): Promise<FadeTickResult<T>>

      One tick (§5.2, §5.4): for each track, drop it if it became safe, if a hand is on it, or if the row no longer holds what this track left there; otherwise write interpolate(...) — and the exact to on the last. Frozen tracks write nothing.
