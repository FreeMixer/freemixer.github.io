    Class InputPatchbay

    The stateful input patchbay: channel → its single physical input, and physical input → its head-amp home. Both maps are keyed by identity (channelKey / physicalInputKey) so a split (two channels, one port) shares one Source. See the module header for the two rules it enforces.

    • patchChannel(channel: ChannelId, patch: SourcePatch, init?: InputInit): Source

      Patch channel to the physical input patch — REPLACE semantics for the channel's ONE physical input (re-patching MOVES the channel; it never sums). If the input is already known — another channel splits it — its existing head-amp record is REUSED (the split shares the preamp) and init is IGNORED, so joining a split never resets the shared phantom / SENS.     seedHeadAmpForPort

    • seedHeadAmpForPort(
          port: string,
          value: HeadAmp,
          capability: HeadAmpCapability,
      ): boolean

      Write the head-amp record for a PORT that has none — independent of any channel, so a box's preamps can be determined before an operator has patched anything to them (spec §8). A SEED, never an assertion: it REFUSES a port that already carries a record and answers false, touching nothing, because a box re-appearing must never lose the operator's parked values to a policy guess. The record it writes is what a later patchChannel to this port inherits, exactly as a split inherits a record another channel created.

      capability is what the PORT declares, and it is required rather than optional: a record carrying none reads as NO_HEAD_AMP, and a projection of such a record is refused as "declares no analog head-amp — state only". A determination that cannot be driven is a number in a map, and §8 is a safety rule about metal before it is a display rule.

      Parameters

      • port: string
      • value: HeadAmp
      • capability: HeadAmpCapability

      Returns boolean

    setHeadAmpForPort

    • setHeadAmpForPort(
          port: string,
          value: HeadAmp,
          capability: HeadAmpCapability,
      ): Source

      Overwrite (or create) a port's head-amp record directly, independent of any channel — the session-RESTORE door (spec §6c: "the kept value has one store, and it is the session file"). Unlike seedHeadAmpForPort this never refuses: a saved show's values carry the SAME authority as an operator's own write, and overwriting is the point — restoring a session replaces whatever the desk currently holds for that port, exactly as restoring a channel's PATCH replaces whatever it sourced before.
