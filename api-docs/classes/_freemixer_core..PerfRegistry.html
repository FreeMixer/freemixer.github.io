    Class PerfRegistry

    A server's whole collection of named op histograms. forOp() returns (creating on first use) a stable PerfHistogram reference a hot-path caller can cache once and call .record() on directly — the ideal shape for a per-request/per-broadcast call site, since it skips the map lookup that record(name, ms) pays every time.
