    Class StationMoldBase<A, S>Abstract

    The station-backed molds' shared trunk (R-096): the claim prologue a patch and a projection both open with, instances, ripples, and project — written once, so the scalar-record and collection molds keep only their own patch loop and their own read of a cell. A mold whose read composes more than the cell holds overrides view.
