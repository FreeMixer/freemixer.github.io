    Class UdpTransport

    Fire-and-forget UDP sender plus an inbound message pump. Owns one bound socket for the connection's lifetime; all datagrams go to host:port.

    open

    • open(onMessage?: (msg: Buffer) => void): Promise<void>

      Create and bind the socket, wiring the message/error listeners. Idempotent.

      onMessage is a convenience for callers that register the handler at open time rather than up front; passing it is the same as calling setMessageHandler first.

      An error raised BEFORE the bind completes (EADDRINUSE, a permission denial) rejects the open — a caller must not be left awaiting a socket that will never bind. Errors after the bind are transport-level noise (the ICMP port-unreachable a silent desk generates) and go to the setErrorHandler sink, which is optional precisely so an adapter can ignore them.
