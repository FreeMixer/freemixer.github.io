    detectedSurfaces

    • detectedSurfaces(): readonly SurfaceDetection[]

      The offer set as it stands — what the LAST sweep found present-but-unconfigured.

      The store behind /surface/detected, and the reason there is only one: two things sweep (the watchdog on its cadence, the /surface/autodetect operation on an operator's fire) and before 2026-08-15 each published its own answer — the watchdog broadcast surface.detected, the operation carried the set in its landing report. A client that fired the probe and one that merely plugged a surface in learned the same fact two ways, with nothing making them agree. Now both go through detectSurfaces, which writes HERE, and the row is the one address either of them converges on.

      Synchronous on purpose: a row read must not wait on hardware. [] before the first sweep is the honest answer — nothing has been offered yet.

      Returns readonly SurfaceDetection[]

    detectSurfaces

    • detectSurfaces(): Promise<SurfaceDetection[]>

      The NEW surfaces on the rig: every registered kind: 'surface' type that is physically present but has NO config entry yet. Probes cold, against the schema's field defaults (the same settings a fresh adapter.add with no overrides would produce).

      Read-only and OFFER-ONLY: never mutates or persists anything, and never auto-adds — the operator confirms via the ordinary add() call. A throwing probe (the probe contract says never, but stay defensive) reads as absent, not an error.

      A type the operator has ALREADY configured is skipped: the watchdog owns presence for configured entries, and re-offering a surface that is merely unplugged would be noise where the missing-hardware alarm is the honest signal. This per-type rule replaces the old first-run gate (hasConfiguredSurface), which silenced detection entirely once any one surface existed — so an X-Touch plugged in on a rig that already had some other surface configured was never noticed at all.

      Returns Promise<SurfaceDetection[]>

    hasConfiguredSurface

    • hasConfiguredSurface(): boolean

      True once at least one kind: 'surface' entry is configured — the first-run gate for detectSurfaces. Autodetect only makes sense before the operator has configured any surface at all; once one exists, the watchdog (not a fresh scan) owns presence.
