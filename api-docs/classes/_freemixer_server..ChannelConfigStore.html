    apply

    • apply(
          id: string,
          channel: ChannelAddress,
          sections?: readonly ("eq" | "gate" | "comp")[],
      ): Promise<void>

      Apply stored config id onto channel atomically (the provider broadcasts it) — the SAME door for an operator-saved config and a read-only factory template.

      sections narrows which of EQ/Gate/Comp land (operator, 2026-09-10: independent switches on the apply). undefined — every OTHER caller, and every existing on-disk config applied before this — means every section the config carries, the door's original whole-state meaning; a caller that switched a section OFF passes the ones still on.

      Parameters

      • id: string
      • channel: ChannelAddress
      • Optionalsections: readonly ("eq" | "gate" | "comp")[]

      Returns Promise<void>

    applyMoves

    • applyMoves(id: string, channel: ChannelAddress): ChannelConfigMoves | undefined

      What applying config id onto channel RIGHT NOW would MOVE off what that channel holds — the read the surface's warning is built from (RULED 2026-09-01). Computed against the SAME body apply hands the provider, synchronously so a resource GET can read it. undefined for an id that names nothing (the item's honest absence). Mutates nothing.

      Capture channel's chain + processing under name; returns the new id.

      family FILES the config beside the factory templates of that family in a picker (ChannelConfig.family).
