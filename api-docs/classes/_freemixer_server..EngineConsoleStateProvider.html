    applyChannelFields

    • applyChannelFields(ch: ChannelSnapshotJson): Promise<void>

      Apply exactly the fields a snapshot CARRIES onto a channel — the session restore's own door with its defaults left off.

      A restore of a whole show resolves absent fields to their kind defaults (a channel the operator never overrode comes back at the default, not at last night's value). A PASTE must not: an absent field there means "the operator did not copy this", and defaulting it would silently move state nobody asked about. Same door, same order, same announce — the defaults are the caller's, which is why they live in applyChannelSnapshot and not here.

      Parameters

      • ch: ChannelSnapshotJson

        the fields to apply, keyed by the channel they belong to

      Returns Promise<void>

    applyPatch

    • applyPatch(snapshot: PatchSnapshot): Promise<void>

      Re-apply a stored routing graph. Each channel's first stored endpoint is set as its primary (replace-semantics, clearing any prior patch), the rest are added as summed crosspoint sources; each output's ONE stored destination is routed (replace-semantics), and an output whose out is ABSENT is routed NOWHERE — the unpatch round-trips rather than leaving the console on whatever it held. Channels absent from the snapshot are left untouched. A no-op without a structural surface.

      Parameters

      • snapshot: PatchSnapshot

      Returns Promise<void>

    captureChannelSnapshot

    • captureChannelSnapshot(channel: ChannelId): ChannelSnapshotJson | undefined

      ONE channel's persisted state, exactly as a session capture sees it.

      Through captureConsole rather than a second assembly pass: a channel's snapshot is built by five passes (the strip, the processor stores, sends, links, routing) and picking one channel out of the finished walk is the only way a copy and a save can be held to the same answer. A copy is one operator gesture, so walking the console for it is not a cost worth a second capture path.

      Parameters

      • channel: ChannelId

        the channel to capture

      Returns ChannelSnapshotJson | undefined

      its snapshot, or undefined when the console carries no state for it at all
