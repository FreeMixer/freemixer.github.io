    ProtectedreadTick

    • readTick(): Promise<void>

      One tick to the sink, carrying the report when a source exists. A thrown read is swallowed and the whole tick skipped — the engine is momentarily busy, and the other gauges wait one period rather than publish beside a report that never came.
