    Function alignCorrection

    • alignCorrection(
          fit: AlignFit,
          applied: AlignApplied,
          travel: { max: number; min: number },
      ): AlignCorrection

      The correction a fit implies for THIS channel, against the line it already holds.

      The alignment delay is applied at the input stage BEFORE every tap point (mixer_rt.c), so the measurement already contains whatever is dialled in: a fit of +2 ms on a strip holding 5 ms means 3 ms, not 2. That is what makes the correction verifiable — apply it and the reading falls toward zero — and it is why this is a DELTA and never an absolute.

      fit.delayMs is positive when the TARGET is late. A late target cannot be advanced, only given back some of its own delay; when it has none left to give, AlignCorrection.clamped says the other channel is the one to move.

      Polarity composes the same way: the tap carries the current inversion, so a residual π means FLIP whatever is set, not "set inverted".

      Parameters

      • fit: AlignFit
      • applied: AlignApplied
      • travel: { max: number; min: number }

      Returns AlignCorrection
