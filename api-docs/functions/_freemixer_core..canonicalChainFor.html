      The CANONICAL arrangement for a strip kind -- what a freshly built strip of that kind carries: defaultBusChain for a bus master, defaultChannelChain otherwise.

      The one place the question "which default chain does this kind get" is answered. Both sides of the persistence round trip ask it here -- the capture prunes an arrangement equal to this one (channel contract revision 5) and the restore's absence clear drives this one back -- so neither can hold a private idea of what fresh means.
