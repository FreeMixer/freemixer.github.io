    Function carriedLookupOf

    • carriedLookupOf(
          declaration: CarriedSeriesDeclaration,
          state: object,
      ): (id: ResourceId) => Readonly<Record<string, number>> | undefined

      Every instance's values out of the collection's state, decoded ONCE: each declared series the state carries is decoded through its own window one time, and the lookup answers an id by position. Memoised on the state object, so N readers of one frame — sixty-four strip streams on one /meters frame — cost one decode of each series and N one-byte lookups, never N decodes (2026-09-01-http2-console-streams.md, amendment 2026-09-02, E1). A new frame is a new object and a new lookup; a state with no index answers nothing for every id.
