    Function defaultAllocation

    • defaultAllocation(name?: string): ConsoleAllocation

      A sensible default console allocation for a fresh server / new session — a small live console the operator can mix on immediately: DEFAULT_INPUT_CHANNELS input channels, a stereo main, 8 aux (monitor) sends, 8 sub-groups, 4 matrix outs, 8 DCAs and 4 FX returns. It is the single source of truth for "the sensible default console": the server seeds it when no allocation is configured, and the session-setup form offers it as its starting values — so the aux / bus / matrix view-switch buttons show something instead of an empty set on a fresh gig.

      These counts obey the rule this module enforces: every banked tier is a whole STRIP_QUANTUM, and they sum to 32 — exactly 4 full banks, no empty faders. A default that tripped bankAlignmentWarning on every fresh server would only teach the operator to ignore the warning.

      No mix-minus is allocated. A mix-minus is MAIN − channelX: the main mix with one channel's contribution subtracted, fed back to a remote participant so they do not hear themselves delayed. It has no per-channel sends — that is precisely what makes it not an aux — so it is defined by a single association ("this channel gets a mix-minus feed → this output"), and its level is the per-destination route trim. It therefore needs no fader, no bank slot and no allocated count: the bus is implicit, created by the channel property and gone with it. See BusAllocation.mixMinus for the state of that field.
