    Function reacHeadAmpDoors

    • reacHeadAmpDoors(
          nodes: Iterable<Readonly<Record<string, string>>>,
      ): ReadonlyMap<string, ReacSegmentNodeProps>

      THE HEAD-AMP DOOR of every reac-pw node, keyed by node.name: the door reacSegmentDoors picks for the segment that node belongs to (reac-head-amp-control.md §14) — the SAME node the /reac/segment/{name} row writes reac.cfg.* through, so a segment has one door whatever is written to it. A source's patch names a CAPTURE node; looking it up here is the whole head-amp resolution, for the write, the caps, the arrival signal and the presence oracle alike.

      A name with no entry is ABSENCE, and only that: the node is not in the snapshot, or its segment has no door. The caller refuses (ABSENT_DEVICE); it never falls back to a name it built — a box with no outputs has NO reac-playback node (FreeREAC/reac-pw#14), and the name a role swap would build answers nothing.

      Each node's own segment is read the way the scan reads it: its declared reac.segment, or its name suffix on a daemon too old to declare one. Where reac-pw left a second node under the same name (a restart's probing zombie), the ESTABLISHED one speaks.

      Parameters

      • nodes: Iterable<Readonly<Record<string, string>>>

        every graph node's TEXT props, node.name among them — the one snapshot the doors are scanned from, so a node and its door can never come from two different reads

      Returns ReadonlyMap<string, ReacSegmentNodeProps>
