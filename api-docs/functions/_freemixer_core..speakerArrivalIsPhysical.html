    Function speakerArrivalIsPhysical

    • speakerArrivalIsPhysical(arrivalMs: number, reachMs: number): boolean

      Whether a measured arrival can be an acoustic one.

      The two lanes' rings are filled in the SAME process callback, so the mic's tap and the feed's tap share a time origin and everything between them — the out stage, the converters, the air, the preamp — costs positive time. So an arrival lives strictly inside (0, reachMs): the low end because the microphone cannot hear the desk before the desk played it, the high end because a lag past the window is a lag the correlation named on the next lap round. Outside, the number is not a distance and the row says out-of-range rather than offering a correction computed from it.

      WHAT THIS CATCHES, AND WHAT CATCHES THE REST. The fit auto-ranges (spec §6, 2026-09-01), so nothing inside the window laps and this fires only for a pair that is not the pair it was thought to be — the reference arriving after the target. Beyond the window, COHERENCE is the refusal: two blocks a whole window apart share no signal at all, so the reading has no confidence behind it and low-coherence says so. Every absence is still visible; which refusal names it is decided by which fact is actually wrong.

      Both bounds are exact rather than tolerant. A tolerance here would be a magic number standing in for the converter round-trip, which the desk does not measure and must not guess.

      Parameters

      • arrivalMs: number
      • reachMs: number

      Returns boolean
