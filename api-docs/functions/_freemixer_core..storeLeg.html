    Function storeLeg

    • storeLeg(
          port: string,
          identify: IdentifyPort,
          previous?: StoredPatchLeg,
      ): StoredPatchLeg

      Turn a live port into what should be WRITTEN DOWN for it.

      A port an enrolled box owns is stored by identity; everything else keeps its name, which is not a compromise — an app stream has no identity to be named by, and inventing one would be a second hand-kept list.

      A leg never DOWNGRADES. identify() failing does not mean "nothing owns this port" — it can mean "not right now": a capture taken while a box is absent, or before its registry entry has loaded (daemon restarting). If this position already held an identity leg AND the live port is still a stagebox port (the vocabulary that identity applies to), the identity survives and the fresh, unidentifiable capture is discarded — losing it here is exactly what re-derived a patch from a port that had gone with its box and wrote back the wrong hardware (rig, 2026-08-21; recurred as the deploy #61 downgrade). A capture that is honestly something else — not a stagebox port at all, an app stream or a loopback — still overwrites: there is no identity for it to preserve, and that is an operator repatch, not an unidentifiable moment.

      Parameters

      • port: string
      • identify: IdentifyPort
      • Optionalprevious: StoredPatchLeg

      Returns StoredPatchLeg
