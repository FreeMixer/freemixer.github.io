    Function eqCoeffs

    • eqCoeffs(eq: EqState, sampleRate?: number): EqCoeffSet

      Fold an EqState into the ordered biquad-coefficient cascade the native mixer runs — the coefficient counterpart of the engine's eqSections. Order is bands (low→high) → HPF → LPF; an OFF band never reaches this set at all, and an ON band that is eqBandIsIdentity reaches it PARKED (enabled: false — present for count/order, skipped by the RT cascade); a 24 dB/oct pass filter is two Butterworth sections, always enabled when on (a pass filter is never identity). A whole-EQ on: false yields an empty set (a bypassed cascade). The coefficient MATHS live here (device-neutral, off the RT thread); the C only runs the biquads with what this returns.

      Parameters

      • eq: EqState
      • sampleRate: number = EQ_DEFAULT_SAMPLE_RATE

      Returns EqCoeffSet
