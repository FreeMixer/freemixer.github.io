    • chainPluginDoors(

      A chain plugin item's doors onto the console's server, late-bound because the rows are composed before the server exists:

      • pluginPathRefusal: a plugin the console has NO PATH for (a CLAP below suitable) is refused by name on the chain's plugin door (CLAP hosting spec §7);
      • chainPluginHosting / chainPluginFormat: the item's tier and format, the console's one realised-hosting answer and the catalog's declared format;
      • admission: the growth doors ask the console's RT admission budget (rt-admission §2.1);
      • onChainPluginChanged: a plugin swapped in place drops the values recorded against the old;
      • onChainPluginsChanged: a plugin item on one strip moves every OTHER feed's detour compensation, so the align lanes are re-pushed. The console and the conformance desk both pass these, so the desk's chain doors are the rig's.
