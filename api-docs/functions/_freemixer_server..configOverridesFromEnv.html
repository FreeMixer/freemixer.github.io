      The SPARSE config overrides a process.env carries — only the keys that are actually set appear, so the result can overlay a config file without unset env fields clobbering set file fields (see overlayConfig). Recognised keys:

      • OPENMIXER_ADAPTER -> adapter
      • OPENMIXER_DEVICE_HOST -> device.host
      • OPENMIXER_DEVICE_PORT -> device.port
      • OPENMIXER_WEB_HOST -> web.host
      • OPENMIXER_WEB_PORT -> web.port
      • OPENMIXER_RIG -> rig.preset
      • OPENMIXER_CONSOLE -> rig.console (IN:OUT pin)
      • OPENMIXER_GIG -> rig.gig
      • OPENMIXER_CATALOG -> rig.catalog
      • OPENMIXER_DEMO_SOURCES -> rig.demoSources (1 = true, anything else set = false)

      The empty string counts as unset for the string knobs — the historical demo-bin env.X || default semantics. Not validated here; parseConfig the result.
