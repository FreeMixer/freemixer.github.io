    Function gateStateToNativeDyn

    • gateStateToNativeDyn(gate: GateState): MixerStripDyn

      Map a GateState to the native GATE dynamics slot — an ACT-BELOW atom whose threshold is the gate's fully-open point (kneeEndDb) and whose expansion ratio is now the state's OWN GateState.ratio field (an explicit operator control — see that field's doc), not derived from the knee width. A hard knee (kneeDb: 0): the widget's kneeStartDb/kneeEndDb/rangeDb remain the LOCAL curve-shape approximation (@freemixer/catalog/gate's gateGainDb, unchanged), which the native atom matches exactly only when ratio sits at the knee-implied value (1 + |rangeDb| / width — the default, GATE_DEFAULT_RATIO in @freemixer/catalog/gate, is chosen to match the DEFAULT knee/range exactly); dialling ratio away from that value is precisely what turns the drawn hard-gate shape into a genuinely gentler expander on the LIVE signal, even though the static curve line keeps drawing the same knee — the live GR overlay (native readout, not this shape) is what shows the operator ratio's real effect. holdMs and hysteresisDb have no atom equivalent this phase (documented gap).

      Parameters

      • gate: GateState

      Returns MixerStripDyn
