    Function retiredPresetNotice

    • retiredPresetNotice(
          preset: "bare" | "demo" | "console" | undefined,
      ): string | undefined

      What to tell the operator at boot about a rig.preset an installed config still names, or undefined when there is nothing to say.

      demo / console both named the path that boots anyway, so the outcome matches the file and the note is a quiet one. bare is different in kind: it named a rig that no longer exists, and the operator gets something ELSE — silently booting a different rig than the file asked for is its own hazard, so that one is loud and explicit.

      Why this is accepted at all, when a missing native engine is refused (see console-rig.ts): the same rule decides both. Degrade only where the operator can perceive the degradation. A console booted without its engine is indistinguishable from a working one, so it must refuse. A console booted where the file said bare is plainly visible — it is a whole desk, and this line says so.

      Parameters

      • preset: "bare" | "demo" | "console" | undefined

      Returns string | undefined
