    Interface AdapterInput

    One enumerable input an adapter exposes — what a Source's patch can reference. The patch is { adapterId, input }; input matches an AdapterInput.input here. Adapters (REAC / console / PipeWire) enumerate these so the source layer can offer "patch this source to …" choices.

    Optional ReadonlygainDefault

    gainDefault?: GainDefault

    The gain this input's preamp is KNOWN to come up at, and how the adapter knows it — see GainDefault. Absent means the adapter has not measured or been told one, and gainDefaultOf resolves the house mic default for it; absent alongside an absent gainRange means the REAC preamp, whose come-up gain IS measured.

    DECLARED here rather than derived from the travel, because a travel says how far a control goes and never where it starts. Only meaningful alongside sensCapable.

    Optional ReadonlygainRange

    gainRange?: HeadAmpGainRange

    How far this input's gain control reaches, in dB of gain, when it differs from the REAC span — see HeadAmpGainRange. Absent (every REAC / console input) means 0..55. Only meaningful alongside sensCapable.

    Readonlyinput

    input: string

    The adapter's own input reference (matches SourcePatch.input).

    Readonlylabel

    label: string

    Human label for the input (e.g. "Stagebox 1 / In 3", "X32 Local 5").

    Optional Readonlymeta

    meta?: Readonly<Record<string, unknown>>

    Free-form adapter-specific metadata (port name, channel index, stagebox id, …).

    Optional ReadonlypadCapable

    padCapable?: boolean

    Whether the input implements the −20 dB analog pad (a REAC box control). Absent = not capable: a software / non-REAC input has no pad, so the UI must not offer one.

    Optional ReadonlyphantomCapable

    phantomCapable?: boolean

    Whether the input can supply +48 V phantom (a head-amp capability). When false/absent a source on this input cannot enable phantom (e.g. a line input or a software node).

    Optional ReadonlysensCapable

    sensCapable?: boolean

    Whether the input exposes a settable analog GAIN — a REAC box's SENS control, an RME mic input's Mic-AN<n> Gain. Absent = not capable: a software input has no preamp to set. The travel it covers is AdapterInput.gainRange; the unit is always dB of gain.
