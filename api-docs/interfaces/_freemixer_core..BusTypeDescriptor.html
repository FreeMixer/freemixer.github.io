    Interface BusTypeDescriptor

    One entry in the BUS_TYPES descriptor table: the single, canonical record of the per-bus-type facts the console used to enumerate by hand in ~5 parallel places (the BusAllocation field, the id synthesis in allocatedBusIds, the roleLabel vocabulary, the setup-form rows, the fader-bay bank sets). Adding a bus type is now ONE table entry.

    interface BusTypeDescriptor {
        allocKey: keyof BusAllocation;
        banked: boolean;
        defaultStereo: boolean;
        hint: string;
        kind:

    ReadonlyallocKey

    allocKey: keyof BusAllocation

    The BusAllocation field this bus type is counted under (e.g. group).

    Readonlybanked

    banked: boolean

    Whether this bus type occupies banked strips — faders the surface pages through in SURFACE_BANK_WIDTH blocks, and which must therefore be allocated in whole STRIP_QUANTUM multiples and counted towards the bank total.

    main is the one type that is not banked: a console gives the main mix its own dedicated master fader, sat outside the paged channel strips (an X-Touch's master fader is not one of its 8). That is why a main of 1 does not violate the "every tier is a multiple of 4" rule and is excluded from bankedStripCount — it is not an exception carved out to make the arithmetic work, it is a different piece of hardware.
