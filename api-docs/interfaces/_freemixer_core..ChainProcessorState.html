    Properties

    admission

    admission: RtAdmissionReadout | null

    What the RT admission door would answer on enabling the item, read before the write (2026-09-26-rt-admission-budget.md §2.5): code: null when it admits, null while the door cannot judge. Derived by the door itself on every read, never stored.

    enabled

    enabled: boolean

    false = bypassed (a pass-through; its output port still exists).

    format

    format: "" | "lv2" | "clap"

    The plugin's declared format (clap, lv2); '' with no plugin.

    kind

    kind: string

    The processor's role (eq, gate, insert, fader, …) — structural, never written.

    label

    label: string

    An insert slot's label (A, B, post, the canonical slots); '' on every other item. Structural, never written — and load-bearing: resolveTap's Post-Insert-A / Post-Insert-B anchors match on kind === 'insert' && label === …, so without it a client cannot resolve those two taps from the rows and has to be told the answer.

    plugin

    plugin: string

    The hosted LV2 URI; '' is an EMPTY slot — the one clear encoding this entity has.

    position

    position: number

    The item's index among the chain's items (order), -1 on a boundary (trim, fader). Writable on every item: a write moves it, the same move a PATCH of the chain's order makes. The position is the only placement fact a client reads or writes.

    preset

    preset: string

    The last preset loaded into the item; '' = none since its plugin was placed. The LOAD DOOR: a write names a preset the plugin ships, judged before the engine (2026-10-01-plugin-presets.md §3).

    presetEdited

    presetEdited: boolean

    Whether a known parameter has moved off the loaded preset; derived, read-only.

    presetMissing

    presetMissing: boolean

    Whether preset names a preset the plugin's catalog does not list; derived, read-only. Provenance only: a session restores the item's values, never the preset.

    presets

    presets: readonly ChainPresetItem[]

    The presets the plugin ships, each judged for the item's realised path; derived, read-only.

    tier

    tier: ChainItemTier

    Where the plugin runs now, derived on every read from the console's hosting answer; '' with no plugin.

    tierReason

    tierReason: string

    The hosting code that answer carries (hosting.linked, hosting.switch-off, …); '' with no plugin.
