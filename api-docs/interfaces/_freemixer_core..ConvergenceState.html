    barrier: number

    The revision of the last whole-console (undoBarrier) commit; 0 when none yet.

    Readonlycontinuous

    continuous: readonly string[]

    Row paths whose state changes WITHOUT a commit (meter/telemetry/analyzer pumps): a client must not read their natural drift as a divergence. Derived from the console's own pump registry — never a list a client keeps.

    Readonlycorrections

    corrections: number

    Total corrections clients have reported since boot — the discovery count.

    heartbeatMs: number

    The heartbeat publish period, ms — how stale "no heartbeat" is allowed to look.

    Committed writes since boot — the console-wide monotonic sequence.
