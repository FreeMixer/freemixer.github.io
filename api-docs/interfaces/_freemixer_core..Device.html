    Interface Device

    One patchable device — a card / stagebox / app unified as a key, a kind, a label, and its input + output port banks. inPorts are the ports the desk takes audio FROM (a card's capture, a stagebox's mic preamps, an app's output); outPorts are the ports the desk routes audio TO (a card's playback, a stagebox's analog outs, a recording app's input). A single-direction device (an app source, an app sink) leaves the other bank empty.

    Properties

    Optional ReadonlyalsaName

    alsaName?: string

    The card's OPAQUE ALSA name (alsa_card.usb-RME_Babyface_Pro__73107815…) — the address /clock/devices/{name} is keyed by, and therefore the ONLY thing that joins a patchable device to its device-policy row (amendment 2026-09-15, later the same evening, to an internal spec). name/title are LABELS two identical cards share; this is an identity. Present on interface devices whose backing nodes carry one; absent on stageboxes, apps, and any dump that omits device.name.

    Optional ReadonlydeviceId

    deviceId?: number

    An interface's PipeWire device.id — a per-boot HANDLE, published as the number it is and never as a key (R-082). Absent on stageboxes and apps, and on an interface whose dump carried no device.id.

    ReadonlyinPorts

    inPorts: readonly DevicePort[]

    Ports the desk can take audio FROM (capture side), numbered 1 … N, in enumeration order.

    Readonlykey

    key: string

    The band KEY — what this device is called within the patchbay, a NAME for every kind: the card's device.name for an interface (the device.<id> fallback only when a dump names no device), the stagebox id for a box, the node name for an app. Not called id because it is not one (R-082): it is a name for every kind, and the one number a card has — its per-boot handle — is deviceId.

    Readonlykind

    kind: DeviceKind

    Which of the three detection strategies produced this device.

    Optional ReadonlylinkState

    linkState?: "absent" | "connected"

    A stagebox's live presence — 'connected' when a box is locked on, 'absent' when it is probing / no box is present. Narrowed from reac-pw's richer reac.link-state; absent on interface + app devices and on a stagebox that publishes no link state.

    Readonlyname

    name: string

    Human label — the SHORT band name (the shortened card name / the box model / app name).

    ReadonlyoutPorts

    outPorts: readonly DevicePort[]

    Ports the desk can route audio TO (playback side), numbered 1 … N, in enumeration order.

    Optional Readonlytitle

    title?: string

    The FULL, unshortened name for the web-ui hover / title (the card's verbatim device.description). Absent when it would only repeat name (an app, a stagebox, or a card whose description was already short).
