    Properties

    cooldownMinutes

    cooldownMinutes: number

    RING MEMORY in minutes: how long a fully-released find's escalation survives, so a chronic ringer re-plants with its doubled holds instead of a fresh history — the whack-a-mole across releases (and restarts) the staged release alone cannot see. 0 = no memory. Default 10.

    holdSeconds

    holdSeconds: FbsHold

    Clean-hold (SECONDS, or 'never') before a LIVE find's notch lifts.

    maxAutoBands

    maxAutoBands: number

    Per-channel cap on auto-planted bands.

    mergeCents

    mergeCents: number

    SAME-RING MERGE RADIUS in cents: a confirmed find within this of a standing FBS band IS that band ringing again (a re-arm), never a new slot. The FFT-jitter window is the floor whatever this says; 0 keeps only that floor. Default 100 (one semitone) — the measured 123/129/135/141 Hz cluster spent four slots on one wedge mode (#170).

    mode

    mode: FbsMode

    Arming mode; off = the watcher never reads this channel.

    notchQ

    notchQ: number

    Planted-notch width (Q); 116 = today's plant. addBand re-clamps per shape (fixed notch → 116, live bell → 8) (finding 5).

    sensitivity

    sensitivity: number

    Detection sensitivity [0..1]; 0 = today's exact gates. The server maps this to the detector's DetectThresholds via thresholdsFor (finding 2).
