    Interface GhostNaming

    The stagebox nodes the desk still POINTS AT but the graph no longer has.

    A box that leaves keeps its patches, because presence law says an absent entity keeps its settings and re-asserts them on arrival — that is what makes swapping in an identical unit a no-op. The cost is that the patches then name a node nobody draws, so the operator cannot reach them. This is what makes them drawable: one device per departed node, presented beside the live ones so the patchbay has something to ghost.

    patchedEndpoints are the node:port strings the desk's patches name, from any door. A device is a ghost when its node matches a stagebox node name and appears in NO detected device. Only the ports the patches actually name are listed — a ghost is what the desk still points at, never a guess at how wide the departed box was; its real width left with it.

    A departed box holding no patches is not returned: it is history, not a thing on this desk.

    boxOf?: (port: string) => string | undefined

    The box a stored patch on this PORT identifies, when the patch names one. An identity, never a name match: the node's suffix is the segment's configured name, so matching it against a registry entry is a guess — and two absent boxes can carry the same label.

    Optional ReadonlynameOf

    nameOf?: (boxId: string) => string | undefined

    The operator's name for a boxId. A name someone typed is desk state and outlives the box; the console shows it rather than the node it happened to be patched through.
