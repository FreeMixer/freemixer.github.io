    Properties

    Readonlykeyed

    keyed: boolean

    The row resolved to a port this rig has, and a head-amp backend owns it. A KEYING fact: it says the write had somewhere to go, never that anything arrived.

    Readonlyreached

    reached: boolean

    The actuator RETURNED without refusal — read off the drive ledger, like the other two.

    The write is QUEUED and the door returns (southbound §6b), so this is false with an empty refused at the instant a client is answered, and the row ANNOUNCES when the drive lands. Nothing here waits for a box: §6c ruled and measured that head-amp is write-only on this wire.

    It is the actuator's report, not hardware confirmation. Neither fabric offers a head-amp readback, so nothing here can see the preamp. Phantom, pad and gain are confirmed at the box, by a person, or not at all.

    false with an empty refused is the honest reading of a write still in flight, or of a port no drive has completed for yet: nothing was refused and nothing has arrived. It is a STANDING fact about the port — what the last completed drive reported stays true until the next one reports, so a refusal is never invisible for a write.
