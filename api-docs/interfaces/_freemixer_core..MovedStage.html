    Optional ReadonlygrFloor

    grFloor?: string

    The declared symbol whose travel's minimum is that reading's floor, the deepest cut the plugin can make (the GR bar's full scale); absent where grRelease is absent.

    Optional ReadonlygrRelease

    grRelease?: string

    The declared symbol whose milliseconds recover the strip's gain-reduction reading of this stage, when the plugin reports it through a clap.meters/1 gain-reduction meter (fx-move §10, "The de-esser"); absent for a stage with no such reading.

    Optional Readonlytempo

    tempo?: MovedTempo

    The block's tempo-sync fields, held by the host on the item; absent for a stage with none.

    Readonlyuri

    uri: string

    The plugin it became, as the item's plugin: the catalogue key urn:clap:<id>.

    ReadonlywalkAfter

    walkAfter: string | null

    The stage it followed in the walk's kind list when it moved; null at the head.
