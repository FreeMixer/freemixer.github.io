    Optional Readonlydefault

    default?: number

    The DECLARED reset/fresh target — where a double-click or Enter lands, mirroring import('./control-limit.js').ControlLimit.default. Absent means the declaration names none and a control offers no reset rather than inventing one from min (widget- foundation.md, Amendment 2026-09-15) — never a literal a call site writes here.

    Optional Readonlyfixed

    fixed?: number

    Format with this many fixed decimals; otherwise significant-digit trim.

    Optional Readonlyinteger

    integer?: boolean

    Round fromNorm / clamp results to an integer.

    negInfLabel?: string

    Readout label for -Infinity (default '-∞'); +Infinity always reads '∞'.

    Optional Readonlysigned

    signed?: boolean

    Format positive values with a leading + (dB-gain style).

    Optional Readonlystep

    step?: number

    Optional UI step hint (engineering units per nudge).

    Optional Readonlytaper

    taper?: Taper

    Position↔value mapping; defaults to { kind: 'linear' }.

    Optional Readonlyunit

    unit?: string

    Engineering unit shown in the readout ('dB', 'Hz', 'ms', 'Q', 'ratio', '%').
