    Interface RenderedBand

    One correction an offline render applied to one track — what was cut, and the measurement that justified it.

    The MEASUREMENT travels with the cut on purpose. A rendered file is a thing an operator keeps and hands on, and "why is there a 4 dB dip at 880 Hz on the cello" is a question the take must be able to answer months later, on a desk that no longer has the analyser state. excessDb and duty are §24's two separate terms — how far above its learned baseline the partial rose when it rose, and how much of its sounding time it spent there.
