    Interface RenderedTrack

    What one track's offline render produced.

    file is the ORIGINAL, which is never modified; rendered is the new file beside it. Both are listed because a take that keeps both must say which is which — §0.5's "the take keeps both files" is a promise about the folder, and this is where the folder says so.

    An EMPTY bands is a real answer and not a failure: HRP found nothing worth correcting on this track, and the rendered file is then byte-identical to the original (the kernel's bit-preserving bypass). That is worth recording rather than hiding, because it is the difference between "we looked and there was nothing" and "we never looked".
