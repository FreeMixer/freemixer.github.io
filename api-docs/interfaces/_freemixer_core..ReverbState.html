    Interface ReverbState

    A native algorithmic reverb (room/plate/hall behind one control surface). size is the comb feedback / tank decay, damping the feedback low-pass, predelayMs the onset delay, width the stereo spread, mix the wet/dry, lowcut/highcut the wet-path filter corners (Hz).

    Readonlyalgorithm

    algorithm: "reverse" | "room" | "plate" | "hall" | "gated"

    Which of the five configurations the kernel runs. reverse and gated are the ROOM comb network handed an OUTPUT STAGE — a windowed time mirror, a hold-and-cut envelope — and not a third reverberator, which is why they are members here rather than a second mechanism (2026-07-15-native-delay-reverb.md, Amendment 2026-09-17).
