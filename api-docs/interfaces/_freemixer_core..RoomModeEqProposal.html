    Interface RoomModeEqProposal

    One proposed narrow cut, derived from one confirmed mode. Not a band until APPLY plants it.

    Properties

    Readonlybounded

    bounded: boolean

    True when the depth or the width hit a ceiling; the surface says so rather than hiding it.

    ReadonlygainDb

    gainDb: number

    The cut, in dB. Always negative: a mode is excess energy and a proposal never lifts.

    Readonlyhz

    hz: number

    The mode's frequency — where the cut sits.

    Readonlypositions

    positions: number

    How many mic positions confirmed the mode this came from — what backs the cut.

    Readonlyq

    q: number

    The band's Q, from the mode's own half-power width, inside EQ_Q_RANGE.

    ReadonlyrequestedDb

    requestedDb: number

    The cut the room asked for before any ceiling — equal to gainDb when nothing bound.

    Optional ReadonlyresidualDb

    residualDb?: number

    After APPLY, the re-sweep's own reading (§4, §6 increment 6): how much of this mode's excess energy still shows in the FRESHEST transfer curve, dB above that curve's own median. 0 once the cut has resolved the mode below the curve's own floor — the honest "nothing left", never a negative number nobody asked for. Absent until the operator has applied this proposal; an absence here is "not yet applied", not "not yet measured".
