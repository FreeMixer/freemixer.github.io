    Interface RoomTransferAccum

    The raw per-bin accumulation both this module and room-impulse.ts build on: the H1 transfer estimate (LINEAR complex, zeroed outside the band) and per-bin coherence, zeroed the same way. Kept over the FULL fftSize / 2 bins (not just the band) so an inverse transform downstream sees a properly zero-padded one-sided spectrum — the same shape coarseDelayOf builds for its own inverse transform (smart-align.ts), reused here rather than restated.
