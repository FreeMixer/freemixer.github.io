    Interface RtSplitFacts

    The split's fact block — what the ENGINE read and runs, published through the actuator contract (§4's GET, §7 lane 1 item 1). Measured facts: the row serves them as-is and never re-derives one. workers: 1 is the unsplit walk.

    ReadonlyfifoPrio

    fifoPrio: number

    The SCHED_FIFO priority the workers were created at — the driver's, read off its tid at the arm (§2.1); 0 when the driver runs no RT policy. A stall assertion on this row is judged only above 0 (§5.1): at the caller's policy a neighbour on the worker's CPU counts as a stall.

    ReadonlymaxWorkers

    maxWorkers: number

    N — 1 + the ranked usable set the engine READ (§3.1, §3.2): the workers knob's live roof (§4). Read at START (the first facts read, before any arm) and re-read at every arm; 1 on an engine that read no CPU set (the single walk is always placeable).

    ReadonlypartitionRatio
