    id: string

    The take's id, and the name of the folder holding it.

    ReadonlylengthFrames

    lengthFrames: number

    Frames captured per track, at rate.

    Readonlyname

    name: string

    The operator's label for this take.

    Optional Readonlyprint

    print?: TakePrint

    The MAIN PRINT written beside the stems by /takes/{id}/export, once one has been made.

    Optional and purely additive, like render: a take nobody has exported carries no such key. It is here rather than derived from a directory listing because a print is a claim about WHICH capture it came off and what happened while it was made — the clip count above all — and a file on a disk carries none of that.

    Readonlyrate

    rate: number

    The sample rate the capture ran at. Playback is only valid when the graph rate equals it — there is no resampler on the VSC path by design — so this is the field a vsc.set refuses on, and it is carried per take rather than assumed from the console.

    ReadonlyrecordedAt

    recordedAt: number

    Epoch milliseconds at the start of capture. A number, where the session / scene / patch envelopes carry an ISO-8601 savedAt string: §4 declares it that way because a take's timestamp is read beside lengthFrames as one position on a timeline, not as a label.

    Optional Readonlyrender

    render?: TakeRender

    The offline HRP render, once one has been run (§0.5). Optional and purely additive: a take recorded before rendering existed carries no such key and loads exactly as it always did.

    Optional ReadonlyreverseRender

    reverseRender?: TakeReverseRender

    The offline pre-hit reverse render that MADE this take, when one did (Amendment 2026-09-17 §G.4). Its presence is what tells a surface that this take is a render of another one.

    ReadonlyschemaVersion

    schemaVersion: 1

    Optional ReadonlysessionId

    sessionId?: string

    The session this was recorded under, when one was loaded.

    Readonlytracks

    tracks: readonly TakeTrack[]

    Optional Readonlyunlinked

    unlinked?: readonly ChannelId[]

    THE CHANNELS THIS TAKE DID NOT CARRY — wanted by the operator and armed by their kind, but with nothing linked into their head input when the take started, so no track was opened for them (§0.2 as amended 2026-09-02).

    STORED, where every other count on the header is derived, because it cannot be derived later: the desk gets re-patched between the show and the morning, and asking today's graph what yesterday's take left out is asking the wrong desk. It is the same class of fact as TakeTrack.xrun — true while the capture ran, and true about the capture for ever after.

    The recorder writes it on every take from here on, [] included: presence of the key is the evidence the console was asked, so a take that declared nothing is told apart from one written before the question existed.
