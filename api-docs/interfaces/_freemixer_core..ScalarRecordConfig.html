    Optional Readonlyfresh

    fresh?: () => S

    What a fresh instance of this row IS — published row-wide so a client never compiles a declared starting value into its own bundle.

    The SAME factory the store makes a new item with, handed to the contract door rather than restated: makeFbsChannelState() is the arming a channel has before anyone arms it, and a panel that needs the notch Q to reset to must read it from the desk or invent one.

    Declared only where the starting point is genuinely row-wide. A row whose fresh state depends on the device behind the instance omits it, exactly as a per-instance travel is withheld from travels() — a plausible wrong default is the defect this door closes, not one it may introduce.

    Optional Readonlylifecycle

    lifecycle?: LifecycleDoors<A>

    The item-lifecycle doors. A scalar row is removable when its ONE store can genuinely lose the item — a send DELETE frees the engine's slot, which is a different fact from a level-0 write even though both end with no send in the ledger.

    Optional Readonlypolicy

    policy?: ResourcePolicy

    What a committed write here means for the session's dirtiness and the operator's history. Absent means the layer default: it dirties the session, is not undoable, and is not a barrier (see ResourcePolicy).
