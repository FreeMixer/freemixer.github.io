    alreadyPlaced?: (device: StageboxDevice) => boolean

    Whether this box is ALREADY PLACED — its identity already feeds AT LEAST ONE channel. A box holding even a partial patch is placed; only a box with ZERO patches is a candidate for a NEW run. Optional, and false by default (every device is a candidate), so a caller that never wires patch identity through keeps today's behaviour.

    2026-09-15: without this, occupied (read from the SAME patch that named this device's own channels) marked a placed box's own run as taken, so the box was offered NO run of its own AND proposed nothing else fits over it — it was reported unplaced / no-free-run for the exact channels it already holds.

    2026-09-17: the gate was "every input patched", so a KNOWN box holding a PARTIAL patch (8 of 16) fell through and was proposed the remainder as a fresh run on unrelated channels — a bulk-placement proposal for a box the operator had already placed on purpose. Partial placement is the operator's own choice; the gate is "at least one patch", never "every one".

    The boxes, IN ROSTER ORDER. Order is the only tie-break: the first box in the list gets the low run (§5's "letter order is a first-fill ordering only"), never the widest one.
