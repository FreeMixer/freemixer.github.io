    Interface InsertChainEntry

    One plugin in the chain being judged, reduced to the facts the checks read. The server fills it from the catalog descriptor; core never imports the catalog.

    A future check reads a further field here rather than a new call-site argument — that is the extension seam. lv2Class / audioInputs / audioOutputs are already carried for the semantic-fit and port-topology dimensions even though no check reads them yet.

    audioInputs?: number

    audioOutputs?: number

    Optional Readonlybypassed

    bypassed?: boolean

    Bypassed slots are in the rack but not in the signal path, so they cost nothing.

    Optional Readonlylatency

    latency?: MsSpan

    The plugin's insert latency at the destination's rate, as a span. undefined = it could not be resolved (never measured, unmeasurable, or nonconforming so nothing may be projected to this rate) — an honest unknown, never a silent zero. A span wider than a point means the figure is parameter-dependent and the operator has moved a latency-bearing control, so only the ENDS are known (see the sweep in PR #336).

    Optional Readonlylv2Class

    lv2Class?: string | null

    LV2 class label ("Reverb Plugin", "Limiter Plugin") — for the semantic-fit check.

    Readonlyname

    name: string

    Display name — a product name, never translated, safe to interpolate.

    Readonlyuri

    uri: string

    The plugin URI (stable id; also the plugin param of a refusal).
