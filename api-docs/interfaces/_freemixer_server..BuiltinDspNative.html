    Interface BuiltinDspNative

    The native strip DSP surface the built-in-processor bridge drives — the verbs of NativeConsoleMixer itself, picked rather than re-typed, so a fake satisfies the same signatures the engine declares. The limiter and the CLAP tempo word are optional: a node without one answers "no stage" (or is reported) rather than a silent success.

    busLane

    • busLane(index: number): number

      BUS index's lane — the slot a bus master takes in the SAME per-lane arrays every input strip and MAIN live in (2026-08-07-one-summing-bus.md §"The build" step 2). index is the bus's position in the node's bus array, which is what import('./software-mixer.js').SoftwareMixer.nativeBusIndexOf resolves — so a caller that has a console bus has its lane in one more call, and nobody re-derives the layout.

      The lane carries the bus's ORDERED STAGES and its ANALYSER tap; its LEVEL is the bus master's own (setMatrixMaster), and setStrip at this index refuses.

      Returns number

    • setStripChainOrder(index: number, steps: readonly NativeStageId[]): boolean

    setStripInsertPoint

    • setStripInsertPoint(
          index: number,
          point: number,
          spec: NativeInsertPoint,
      ): false | NativeInsertPorts

      Arm, rack or drop strip index's INSERT POINT point — the send/return port pair a hosted plugin chain hangs off, at the place the strip's chain declares.

      Two moments, never one. { at, channels } ARMS the ports and answers with their names; { live } says whether a chain is actually LINKED between them and the lane should take the detour. Racking a point before its links are laid would read a return nothing feeds — connect-new-before-disconnect-stale, in the native node.
