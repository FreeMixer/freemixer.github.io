      The channels this mixer presents.

    • OptionalconsoleProfile?: string

      The console appliance this deployment declares (a ConsoleProfileId, default openmixer). It CAPS the seeded allocation and GATES what the console can build, so a restricted desk is enforced even without the UI: a declared allocation that violates the appliance is rejected, and every seed is clamped through capAllocation. An unknown id falls back to the unrestricted openmixer profile.

    • main: { input: { l: string; r?: string } }

      The main mix bus sink ports the channels sum into.

    • modHost: { host: string; port: number }

      mod-host endpoint for the plugin inserts. Defaults to the standard 127.0.0.1:5555. .prefault({}), not .default({}) — see config.ts's note: Zod 4's .default() would hand back {} verbatim on an omitted modHost, skipping the nested host/port defaults; .prefault({}) re-runs {} through the inner schema so they still resolve.
