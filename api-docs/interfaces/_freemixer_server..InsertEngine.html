    OptionalinsertChannels

    • insertChannels?(): readonly ChannelId[]

      Every channel this console holds a rack for — the instance set all four insert rows walk.

      EMPTY RACKS ARE IN IT. The rack row is the collection a removal announces on: it names the plugins that remain, and a stream's opening burst has to carry it or a client holds no prior state for the frame the removal sends. A set narrowed to non-empty racks would make the row VANISH exactly when it emptied, which is the one moment it has something to say.

      Absent, the rows enumerate nothing and answer only what they are asked about.

      Returns readonly ChannelId[]

    OptionalinsertControlsOf

    • insertControlsOf?(uri: string): readonly PluginParam[] | undefined

      The CONTROL ports of a plugin, as the served descriptor declares them (/plugins/{uri}, params[] with kind: 'control') — the parameter row's instance roster and each instance's travel. Absent, or answering undefined for a URI, the row enumerates no parameter for that plugin and publishes no travel: a console without a catalog declares nothing it cannot stand behind, and a write still reaches the port by its symbol.

      Parameters

      • uri: string

      Returns readonly PluginParam[] | undefined

    OptionalinsertOffer

    • insertOffer?(channel: ChannelId): readonly string[] | undefined

      The plugins this strip may rack — the served roster narrowed by the strip's width, the offer OPTIONS publishes as plugins.values. Absent, or answering undefined, no vocabulary is published: a console without a catalog declares nothing it cannot stand behind.
