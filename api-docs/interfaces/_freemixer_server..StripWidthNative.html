    Interface StripWidthNative

    The narrow native surface buildNativeStripWidthHook drives — the strip-width subset of NativeConsoleMixer: the in-place width reconfigure (which reports success — false on a failed port swap) and the live per-strip input-port names. Kept minimal so the hook is unit-testable against a recording fake, no addon needed.
