    Interface StructuralDsp

    The structural-DSP capability the server drives — exactly the structural surface of import('@freemixer/audio-engine').SoftwareMixer. Declared here (not imported from the engine) so the server compiles against the contract before the engine merge lands, and so tests can supply a fake. The live SoftwareMixer satisfies it structurally once it carries the 4-arg setSend + the buses()/dcas()/matrices() enumerators.

    OptionalbusOutputDelayActuates

    • busOutputDelayActuates?(bus: ChannelId): boolean

      Whether this bus's per-destination DELAY REACHES AUDIO, or is stored only.

      Two native stages carry it and a bus is in exactly one: MAIN's destination rides the per-route output stage, every other native bus rides its OWN bus-lane output stage (2026-08-31-smart-alignment.md §9c). A bus with neither — and an output patched NOWHERE, whatever stage it owns, since a per-destination delay with no destination has nothing to reach — stores the value while no RT cycle consults it. A reader that OFFERS one of those numbers as a correction is offering a write that changes a value and moves no loudspeaker, which is why loudspeaker alignment (§9b) asks this before it offers an APPLY.

      Optional: a surface that draws no such line does not answer, and a reader treats the silence as "it does" rather than refusing every console that never had the distinction.

      Parameters

      • bus: ChannelId

      Returns boolean
