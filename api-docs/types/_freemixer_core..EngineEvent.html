    • {
          channel: ChannelId;
          kind: "refused";
          param: SurfaceWriteFact;
          reason?: string;
          refusal?: Refusal;
      }

      A write THIS client made was refused by the row that owns the fact — fanned out by a SurfaceHost whose write door answers (SurfaceEntityWrites), never by the engine, which refuses nothing after the fact.

      It exists because silence is not an answer for HARDWARE. A motor fader the operator moved stays where the hand left it, so a refused move leaves the surface showing a value the desk never took, with no frame coming to correct it. On this event a surface repaints the fact from SERVED truth — the same repaint an accepted write gets from its broadcast, so there is one path and one source of truth, and no client-side mirror anywhere.
