    The console's own interpreter, the ONE script that runs inside the sandboxed iframe (§6.6). It reads MOD's own attributes — every control is mod-role="input-control-port" with a mod-port-symbol, and its mod-widget says how it is driven (switch/bypass toggle on a click, anything else — film, the knob — follows a vertical drag) — posts modgui-control to the parent, and applies an incoming modgui-values push: the value on data-value and the --mod-value custom property, and, for a film strip (a background image of square frames laid side by side, as MOD draws its knobs and switches), the frame for that value by background-position. It touches nothing else: no fetch, no storage, no navigation — the sandbox token list already refuses all three, this script asks for none of them either.
