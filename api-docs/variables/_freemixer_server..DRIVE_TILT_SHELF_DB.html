    Variable DRIVE_TILT_SHELF_DBConst

    DRIVE_TILT_SHELF_DB: 6

    Map a console DriveState to the native DRIVE stage, DESIGNING its four biquad sections at the live rate — @freemixer/core's rbjSection, the one RBJ transcription in the codebase, exactly as the EQ and the gate key already do. The C only RUNS them.

    FOUR sections, and every one of them has a reason it cannot be built in the C:

    • bandCoeffs — the complementary split's low-pass at bandHz. Butterworth Q, because the other half of the split is x − LP(x) and the pair must reconstruct flat.
    • tiltCoeffs / tiltInvCoeffs — a ±TILT_SHELF_DB high shelf at bandHz and its EXACT inverse. The inverse is the same section with the gain NEGATED, which for an RBJ shelf is the numerator and denominator swapped, so the pair cancels to unity on the dry path and what tilts is only how hard each octave hits the knee.
    • hfCoeffs — the post-curve roll-off at the corner hfRolloff names. off still designs a section (at the ceiling) so the C never runs an uninitialised one; the hfRolloff FLAG is what decides whether it runs.

    mix crosses as the PERCENT the row declares; the C divides where it resolves the atom, once.
