Catàleg de plugins

Què hem mesurat de cada plugin.

Cada plugin es carrega, s’executa i es mesura en un dispositiu real abans que OpenMixer l’ofereixi. Es vigila que el callback d’àudio no faci assignacions de memòria, bloquejos ni crides al sistema. També es mesuren el cost de CPU i la latència. Aquests són els registres de 2016 plugins en 2 plataformes, agrupats segons el que cada plataforma ha pogut acceptar.

Què ha acceptat cada plataforma.

El mateix plugin pot superar la prova en una plataforma i ser refusat en una altra, de manera que cada plataforma es compta per separat.

Cada plugin es prova per a cada manera com es pot oferir. S’accepta quan una d’aquestes maneres supera totes les mesures. S’accepta amb condicions quan el millor que pot fer és executar-se en un procés a part. Es refusa quan no es pot oferir de cap manera.

La prova d’estabilitat de llarga durada no formava part d’aquests registres, de manera que cap plugin s’ha jutjat per aquest motiu ni en un sentit ni en l’altre.

Les dades

D’on surten aquestes xifres.

Cada xifra d’aquesta pàgina es llegeix dels registres de qualificació, que són públics. Els registres estan fixats en una versió. Un script regenera les dades de la pàgina a partir d’aquesta versió i comprova que no hi ha cap diferència.

  • Els registres de qualificació
  • El format de les dades i com s’actualitzen

Un resultat val per al fitxer i la versió que consten a la fila. Si manteniu un plugin i una fila és errònia o ha quedat antiquada, cada fila oberta té un enllaç a un formulari per informar-ne.
