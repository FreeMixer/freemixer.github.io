Tech docs — Abstractions catalog

Every reusable element, in one place.

Two kinds of code exist here: a reusable element, or configuration composing one. This page is the inventory of the first kind — types, components, widgets, libraries and modules — so a change reaches for what already exists before it writes something new.

The web-ui and native-C halves below are curated by hand, because typedoc reads TSDoc, not Vue single-file components or C headers. The @openmixer/core and @openmixer/server halves are generated straight from their TSDoc comments — 1354 exported symbols, 1290 of them with a summary.
