Reading the verdicts

What each verdict means.

In-process
Passed every measured dimension. Qualified to run inside the engine’s own process.
Isolated
Runs, in a separate process. The deciding reason says why it is not in-process.
Not fully measured
At least one dimension was not measured, so no verdict is given. Runs in a separate process.
Refused
The qualifier could not load or run it.

A dimension counts as measured only past its threshold: 1000 load cycles, a 3-hour soak, and a CPU cost of at most 5 % of one core at the 95th percentile. The worst dimension decides the verdict.

The data

Where these figures come from.

Every figure on these pages is generated from one run file, published with its schema. The same file is installed on consoles by the openmixer-plugin-catalog package.

  • This run’s data (plugin-catalog/runs/2026-10-01.json)
  • The schema and how the fields are derived

A result is for the package version and date shown on the plugin’s page. If you maintain a plugin and an entry is wrong or out of date, each plugin page has a link to report it.
