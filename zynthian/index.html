Zynthian

A steadier plugin host for your Zynthian.

Plugins that cannot take the set down, menus built from what each plugin did on your device, and figures measured against mod-host and jalv.

OpenMixer's plugin host, plugin-hostd, runs the LV2 and CLAP plugins of a Zynthian in workers of their own. It works on a Raspberry Pi 4 or 5 with the Vangelis system and needs nothing from the OpenMixer console.

Below is everything it gives you, with the version each part shipped in. The guide has the install steps, the settings and the full tables.

A crash stays in one plugin

If a plugin crashes, only that plugin stops. The rest of your set keeps playing.

Every plugin runs in a worker process of its own, or shares one with the plugins next to it in a chain. A worker that dies is started again by the daemon with its settings and the links it had made, so a bad plugin costs you a moment, not the show.

A chain in one worker

Plugins in series share one worker and one JACK client. You get most of the memory back.

The daemon plans what can run together: a run of plugins in series is one worker, and a parallel slot, the mixer strip or a jalv plugin ends the run. A processor that runs alone has a Grouping entry in its options that says why. Grouping is off until you turn it on.

  • The load is about twice the 48 kHz figure on every host and the order holds. What loads is what was measured

A plugin is pinned the first time it is used. If its files change, it is measured again.

The pin ties a plugin name to the exact file that was qualified. The host loads only pinned plugins, so a plugin that was swapped or updated behind its back does not run on trust.

plugin-qualify runs each plugin on the device and writes what it found: latency, real-time safety and cost. The menus are built from those records. The records package ships ready-made results for the Pi 5, and a sync in the background checks only the plugins whose files changed.

A plugin that breaks the rules is isolated

A plugin that corrupts the host's own state is moved to a worker of its own.

Every plugin call saves and checks the registers a function must keep. A plugin that changes one is caught and runs alone from then on, so it cannot take the rest of a chain with it.

The converter rewrites the plugins of a snapshot saved under jalv, and keeps a preset in the Factory or User bank it belongs to. The round trip of a snapshot that holds a plugin-hostd instrument is still to be measured on the device.

Big synths use all four cores

A synth that splits its voices into tasks plays more notes, because every core helps.

The host starts helper threads, pinned to the cores the plugin may use. A plugin gets them only after qualification found it safe for real time with the helpers running and faster with them. Any other plugin runs as before. You do not set anything on Zynthian.

  • The mean cost of one block with 48 voices fell from 3335.5 to 857.9 µs, 3.9 times faster, with no block over its deadline. This is a test plugin; Surge XT has no figure of this kind because it does not split its voices.Read with: omx-clap-host 0.29.0, test plugin of 16 tasks per block, Raspberry Pi 5 · 48 kHz, 256 frames

Ducker, doubler and tone

Music under a voice, a double-tracked sound without a second take, and a tone tilt with a DJ filter.

omx-ducker pulls the programme down while a key is heard, by a set depth with attack, hold and release. omx-doubler adds up to four slightly delayed, detuned and drifting copies spread across the stereo field. omx-tone tilts the whole tone darker or brighter about a pivot and sweeps a resonant DJ filter with one knob. They are in the next omx-plugins release.

Nothing quietly hands a plugin to another host. Adding a refused plugin tells you why and adds nothing. You can still pick jalv or mod-host yourself as an engine; they are never chosen for you.

You choose how strict the host is

Qualified only, warn on crashes or load all. The choice is saved and applies at once.

Plugin bar (Admin > Audio > Plugin bar, or the plugin list options): choose qualified only, warn on crashes (the default) or load all. The choice is saved and applies at once, with no restart. A plugin below the bar runs in a plugin-hostd worker of its own, never in another host, and with qualified only it is not offered.
